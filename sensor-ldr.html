Luminosidade

LDR

Resistor que varia conforme a quantidade de luz incidente.

Conceito: componente resistivo cuja resistência elétrica muda de acordo com a intensidade de luz recebida.

Princípio de funcionamento: efeito fotocondutivo — a luz incidente libera elétrons no material semicondutor, reduzindo a resistência quanto maior a luminosidade.

Especificações: resistência de cerca de 1kΩ (com luz) a mais de 1MΩ (no escuro); tempo de resposta na ordem de dezenas de milissegundos.

Tipo de sinal: Analógico (utilizado com um divisor de tensão).

Aplicações: controle automático de iluminação pública e industrial, sensores crepusculares.

Exemplo de uso: acionar um relé de iluminação automaticamente quando a luminosidade do ambiente cair abaixo de um limite definido.

Fabricantes/modelos: componente genérico, sem marca única (códigos comerciais comuns: GL5528, GL5516).

Exemplo de código Arduino

const int pinoLDR = A0;
const int pinoRele = 7;

void setup() {
  pinMode(pinoRele, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(pinoLDR);
  Serial.print("Luminosidade: ");
  Serial.println(luz);

  if (luz < 300) {
    digitalWrite(pinoRele, HIGH); // escuro: liga iluminacao
  } else {
    digitalWrite(pinoRele, LOW);  // claro: desliga iluminacao
  }

  delay(500);
}
