PIR HC-SR501

Detecção de presença por radiação infravermelha.

Conceito: sensor infravermelho passivo que detecta a variação de radiação térmica emitida por corpos em movimento.

Princípio de funcionamento: uma lente de Fresnel foca a radiação infravermelha de diferentes zonas sobre um elemento piroelétrico, que detecta a variação causada pelo deslocamento de uma fonte de calor.

Especificações: alcance ajustável de 3 a 7m; ângulo de detecção de cerca de 120°; alimentação 5–20V; tempo de retenção ajustável por trimpot.

Tipo de sinal: Digital.

Aplicações: iluminação automática de ambientes, sistemas de segurança e alarme.

Exemplo de uso: acender automaticamente a iluminação de um corredor industrial ao detectar a presença de uma pessoa.

Fabricantes/modelos: módulos genéricos baseados no chip BISS0001, vendidos por diversas marcas.

Exemplo de código Arduino

const int pinoPIR = 3;
const int pinoLed = 8;

void setup() {
  pinMode(pinoPIR, INPUT);
  pinMode(pinoLed, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int movimento = digitalRead(pinoPIR);

  if (movimento == HIGH) {
    digitalWrite(pinoLed, HIGH);
    Serial.println("Presenca detectada");
  } else {
    digitalWrite(pinoLed, LOW);
  }

  delay(200);
}
