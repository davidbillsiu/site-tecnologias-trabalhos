Temperatura e Umidade

DHT11

Sensor digital simples de temperatura e umidade do ar.

Conceito: sensor digital combinado que mede temperatura e umidade relativa do ar em um único módulo.

Princípio de funcionamento: um termistor NTC mede a temperatura e um sensor capacitivo de umidade mede a variação de capacitância de um filme higroscópico; um chip interno converte as duas leituras em um sinal digital.

Especificações: temperatura 0–50°C (±2°C); umidade 20–90% RH (±5%); alimentação 3,3–5V; 1 leitura por segundo.

Tipo de sinal: Digital (protocolo próprio de um fio).

Aplicações: monitoramento ambiental, estações meteorológicas simples, estufas.

Exemplo de uso: monitorar a temperatura e umidade de uma sala de servidores, emitindo alerta se os valores saírem da faixa ideal.

Fabricantes/modelos: Aosong (fabricante original do sensor); módulos vendidos por diversas marcas genéricas.

Exemplo de código Arduino

#include <DHT.h>

#define DHTPIN 2       // pino digital conectado ao sensor
#define DHTTYPE DHT11  // define o modelo do sensor

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float umidade = dht.readHumidity();
  float temperatura = dht.readTemperature();

  if (isnan(umidade) || isnan(temperatura)) {
    Serial.println("Falha na leitura do DHT11");
    return;
  }

  Serial.print("Umidade: ");
  Serial.print(umidade);
  Serial.print(" %  Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" *C");

  delay(2000);
}
