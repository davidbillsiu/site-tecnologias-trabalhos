Sensor Capacitivo LJ18A3

Detecção de sólidos e líquidos, metálicos ou não.

Conceito: sensor de proximidade capaz de detectar qualquer tipo de material próximo, metálico ou não.

Princípio de funcionamento: forma um campo elétrico capacitivo; a aproximação de qualquer material altera a constante dielétrica do meio e, consequentemente, a capacitância medida pelo circuito oscilador.

Especificações: distância de detecção de até 10mm (conforme o modelo); alimentação 6–36V DC; saída NPN ou PNP.

Tipo de sinal: Digital (NPN/PNP).

Aplicações: detecção de nível de líquidos em tanques, controle de embalagens plásticas ou de vidro.

Exemplo de uso: detectar o nível de líquido em um tanque plástico sem precisar de contato direto com o produto.

Fabricantes/modelos: fabricantes genéricos; linhas profissionais como Omron, Autonics e Pepperl+Fuchs.

Exemplo de código Arduino

const int pinoSensor = 4;

void setup() {
  pinMode(pinoSensor, INPUT);
  Serial.begin(9600);
}

void loop() {
  int estado = digitalRead(pinoSensor);

  if (estado == LOW) {
    Serial.println("Material detectado (liquido ou solido)");
  } else {
    Serial.println("Nenhum material detectado");
  }

  delay(500);
}
