Temperatura

LM35

Medição analógica de temperatura com saída linear em tensão.

Conceito: sensor analógico de temperatura de precisão, com saída de tensão proporcional à temperatura em graus Celsius.

Princípio de funcionamento: uma junção semicondutora interna gera uma tensão que varia linearmente com a temperatura, na proporção de 10 mV por °C.

Especificações: faixa -55 a 150°C; precisão ±0,5°C a 25°C; alimentação 4–30V; saída analógica linear.

Tipo de sinal: Analógico.

Aplicações: controle de temperatura em painéis elétricos, monitoramento de motores e equipamentos.

Exemplo de uso: leitura da temperatura de um painel elétrico via entrada analógica do Arduino, convertendo a tensão lida em graus Celsius.

Fabricantes/modelos: Texas Instruments (fabricante original); diversos clones equivalentes.

Exemplo de código Arduino

const int pinoLM35 = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int leitura = analogRead(pinoLM35);
  float tensao = leitura * (5.0 / 1023.0);
  float temperatura = tensao * 100.0; // 10 mV por grau Celsius

  Serial.print("Temperatura: ");
  Serial.print(temperatura);
  Serial.println(" *C");

  delay(1000);
}
